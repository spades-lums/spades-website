# public/files

Documents we link to and hand out as-is: rules PDFs, reports, forms. Files here are
copied to the site unchanged and keep their path, so `public/files/psifi/rules/robotics.pdf`
is downloadable at `/files/psifi/rules/robotics.pdf`.

Not for photos or graphics used inside pages — those go in `src/assets/images/`, so Astro
can optimise them. Nothing private: this folder is public to the internet.

Example: `public/files/psifi/rules/line-following.pdf`
