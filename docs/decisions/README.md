# Decision records

One short file per decision that would be expensive to reverse, or that a newcomer would
otherwise be tempted to undo without knowing why it was made.

Each record has the same four headings: **Context**, **Decision**, **Alternatives
considered**, **Consequences**. Number them in order and never renumber. A decision that
stops being true is not deleted — add a **Status: superseded by 00N** line at the top, so
the reasoning stays readable.

Example: `004-behold-for-instagram.md`
