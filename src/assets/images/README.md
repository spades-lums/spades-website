# src/assets/images

Photos and graphics used inside pages. Astro optimises and fingerprints anything imported
from here, so prefer this over `public/`.

Mirror the content structure: a photo for `src/content/teams/3d-printers.md` lives at
`src/assets/images/teams/3d-printers/hero.jpg`.

Not for PDFs or downloadables (`public/files/`), logos (`../logos/`), or SVG marks (`../marks/`).
