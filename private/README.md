# private

Local-only working files. **Git ignores everything in this folder except this README.**

Put here anything that must not be published:

- the members roster spreadsheet (`*.xlsx`, `*.csv`) — it contains student roll numbers
- exports and scratch files you do not want in the repository
- anything a person has not agreed to make public

This repository is public to the whole internet. Roll numbers are personal data. If one is
ever committed, assume it has been copied and cannot be unpublished.

Scripts in `scripts/` read their input from here. Share the real files through the society's
Google Drive, not through Git.
